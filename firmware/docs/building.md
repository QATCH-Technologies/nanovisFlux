# Building

## Requirements

- Arduino IDE 2.3.x
- Teensyduino support package
- Teensy 4.1
- AccelStepper library

## Install Dependencies

Open the Arduino Library Manager and install:

- AccelStepper

No additional libraries are required.

## Build

1. Open the project in Arduino IDE.
2. Select **Teensy 4.1**.
3. Select the correct COM port.
4. Click **Verify**.
5. Click **Upload**.

## Recommended Settings

| Setting | Value |
|---------|-------|
| Board | Teensy 4.1 |
| USB Type | Serial |
| Optimize | Faster |

Additional build settings may be documented here as the project evolves.
